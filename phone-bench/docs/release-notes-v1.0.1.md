# Phone Bench v1.0.1 リリースノート

## GitHub Releases 向け

### 修正

- 端末の画面でスクロールバーを隠すようにした。パソコンの Chrome で「スクロールバーを常に表示」の設定だと、スクロールバーの分（約15px）だけページの表示幅が狭くなり、iPhone と違うレイアウトになっていた
- 倍率 100% のときは端末の枠に transform を付けないようにした。Chrome は transform で縮小した別オリジンの iframe で `backdrop-filter`（すりガラス）を正しく描けず、ナビゲーションバーなどの右端が灰色の帯になることがあった。100% なら正しく表示される

### 既知の制限

- 倍率が 100% 以外のときは、すりガラスの要素の表示が崩れることがある（Chrome の描画の不具合）。すりガラスの見た目は 100% で確かめる

## Chrome ウェブストア向け

・パソコンのスクロールバーの分だけページの幅が狭く表示される問題を直しました
・倍率 100% で、すりガラス（ぼかし）を使ったナビゲーションバーなどが正しく表示されるようにしました
