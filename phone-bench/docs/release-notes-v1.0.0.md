# Phone Bench v1.0.0 リリースノート

## GitHub Releases 向け

### 概要

localhost や公開中の URL を、複数の iPhone の画面に並べて同時に確認する Chrome 拡張機能の初版です。

### 追加した機能

- ツールバーのボタン・右クリックメニューから、表示中のページ（またはリンク先）をエミュレーター画面で開く
- 10機種（iPhone 17 Pro Max〜iPhone SE 第3世代）、最大12台を並べる。追加・複製・削除・並べ替え
- 全端末に同じ URL を開く欄と、端末ごとの URL 欄。スキーム省略時はローカルのホストを http、それ以外を https で補う
- Safari 表示とホーム画面アプリ表示、縦向きと横向き、倍率（画面に合わせる・100%・75%・50%）
- スクロール同期、端末ごとの戻る・進む・再読み込み・新しいタブで開く
- iframe 内の通信を iOS Safari の User-Agent で送り、`navigator`・`screen` の値も iPhone に合わせる
- エミュレーター画面のタブに限り、X-Frame-Options と CSP の埋め込み制限を外す
- つながらない URL では、原因の確かめ方を画面に表示

### 影響範囲

- 新規の拡張機能（`phone-bench/`）。既存の拡張機能への変更なし
- 通信の書き換えは `declarativeNetRequest` のセッションルールで、エミュレーター画面のタブ ID に限定

### 既知の制限

- 描画は Chrome（Blink）のまま。WebKit 固有の描画差は再現しない
- `(hover: none)`・`(pointer: coarse)`・`env(safe-area-inset-*)`・devicePixelRatio はパソコンの値のまま
- 機種や表示モードを変えると、その端末のページを読み込み直す
- カメラ・マイク・位置情報・クリップボードの読み取りは iframe 内で使えない（許可が拡張機能に記録され、ほかのサイトへ引き継がれるのを防ぐため）
- ログインが必要なサイトは、サードパーティ Cookie の設定によってはログイン状態にならない

### 確認したこと

- 単体テスト 54件（`npm run test`）
- Chromium に読み込んだ E2E（`npm run e2e`）：埋め込みを拒むヘッダーを返すページを3台で表示、通信と JS の User-Agent、端末ごとの幅と screen.width、iframe 内のリンク移動の追跡、スクロール同期、横向き、接続失敗の案内（URL 欄からと iframe 内の移動から）、ほかのタブに影響しないこと

## Chrome ウェブストア向け

はじめてのリリースです。

作っているページが iPhone でどう見えるかを、複数の機種で同時に確かめられます。確認したいページでツールバーのボタンを押すと、並んだ iPhone すべてにそのページが表示されます。localhost:3000 のような開発中の URL もそのまま開けます。

・10機種から選んで、最大12台まで並べられます
・端末ごとに別の URL を開いて、本番と開発中の画面を見比べられます
・Safari 表示とホーム画面アプリ表示、縦向きと横向きを切り替えられます
・スクロールをそろえて、同じ場所を見比べられます
